# Networkwalks-Mediroza-Week4-Penetration-Testing

## Web Application Security Assessment | Networkwalks Week 4 Capstone

This repository contains my practical work, evidence, and documentation for the **Week 4 Capstone Project** completed during my **Networkwalks Cybersecurity Internship**.

The project involved an authorized security assessment of the **Mediroza General Hospital** web application. The assessment focused on identifying vulnerabilities, validating their security impact, documenting evidence, and providing remediation recommendations.

## 🎯 Objectives

The main objectives of this assessment were to:

- Perform reconnaissance against the authorized target
- Identify web application security weaknesses
- Test the patient portal authentication mechanism
- Analyze access to protected patient reports
- Perform authorized PDF password auditing
- Inspect PDF metadata
- Identify exposed backup resources
- Analyze sensitive information exposure
- Document findings and evidence
- Provide security remediation recommendations
